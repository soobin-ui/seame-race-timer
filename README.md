# 2026 SEA:ME HACKATHON — 스케일카 레이스 스톱워치 & 랭킹

스케일카 자율주행 대회의 팀별 주행 기록을 측정하고 실시간 순위를 매기는 도구입니다.
**인터넷·설치·로그인이 전혀 필요 없습니다.** `index.html` 파일을 더블클릭하면 끝.

---

## 빠른 시작
1. `index.html`을 더블클릭해서 브라우저(크롬/엣지 권장)로 엽니다.
2. 데이터는 브라우저에 자동 저장됩니다(localStorage). 새로고침·재실행해도 유지됩니다.

> ⚠️ **현장 운영 팁**: 대회 시작 전 노트북·브라우저를 정하고 끝까지 같은 환경에서
> 쓰세요. 데이터는 해당 브라우저에만 저장됩니다. 만일을 대비해 중간중간
> **💾 백업(JSON)** 을 눌러 파일로 저장해두면 다른 PC로도 옮길 수 있습니다.

## 화면 구성 (위 → 아래, 풀스크린)
1. **▶▶ 동시 출발** (맨 위, 크게) + 둘 다 리셋
2. **🏁 팀 추가** 바 (이름만 입력해 즉시 등록) + 정지 시 자동 저장 토글
3. **TRACK 1 · TRACK 2** 큰 카드 (각 트랙별 팀 선택·대형 타이머·정지 버튼)
4. **LIVE RANKING** 실시간 순위표 (풀폭)

> 행사 LED/프로젝터 대형 화면에 맞춰 요소가 화면 폭에 따라 크게 확대됩니다.

## 사용 순서

### ① 팀 등록 (기록하는 화면에서 바로)
- 컨트롤 패널의 **🏁 팀 추가** 칸에 팀 이름을 입력하고 **Enter**(또는 ＋ 등록).
- 이름만 등록하면 됩니다 — 기록은 타이머로 측정하거나 순위표에서 직접 입력.
- 등록한 팀은 바로 순위표와 두 트랙의 팀 선택 목록에 나타납니다.

### ② 레이스 측정 · 2트랙 (동시 출발)
두 대(TRACK 1·2)가 **동시에 출발**해서 각자 결승선을 통과할 때 따로 기록합니다.

1. **TRACK 1**과 **TRACK 2**에 각각 이번에 달릴 팀을 선택합니다.
   (배지에 `다음 ▶ 1차`처럼 다음 저장 칸 표시)
2. **`▶▶ 동시 출발`**(또는 **Space**)을 누르면 두 타이머가 같은 순간 시작됩니다.
3. 각 차가 결승선을 통과하면 그 트랙만 정지:
   - **TRACK 1 정지** = `■ 정지` 버튼 또는 키보드 **A**
   - **TRACK 2 정지** = `■ 정지` 버튼 또는 키보드 **L**
   - (한 명이 양손으로 A·L 키를 잡으면 두 차를 거의 동시에 세울 수 있습니다.)
4. **정지하는 순간 그 트랙 팀의 다음 빈 칸(1차 → 2차)에 자동 저장**되고, 그 트랙 타이머만 0으로 리셋됩니다.
   - 같은 팀이 한 번 더 달리면 → 정지 시 자동으로 **2차**.
   - 잘못 저장됐으면 화면 하단 알림의 **↩ 되돌리기**.
5. **둘 다 리셋**(또는 키보드 **R**)으로 두 타이머를 한 번에 0으로. 각 트랙의 **↺ 리셋**은 그 트랙만.

**조작 요약**: `Space` 동시 출발 · `A` TRACK 1 정지 · `L` TRACK 2 정지 · `R` 둘 다 리셋

> - 자동 저장을 원치 않으면 **`정지 시 다음 기록 칸에 자동 저장`** 토글을 끄고, 각 트랙의 **`1차 수동`/`2차 수동`** 버튼으로 직접 넣습니다.
> - 두 기록이 모두 찬 팀은 정지해도 덮어쓰지 않습니다. 수정은 순위표의 **E** 또는 수동 버튼으로.
> - 한 트랙만 단독으로 다시 달릴 땐, 그 트랙의 `▶ 시작` 버튼(또는 A/L 키)으로 개별 출발할 수 있습니다.

## 순위표 행 버튼 (Actions)
각 팀 행 오른쪽에 **E · R · D** 버튼이 있습니다.
- **E** (수정): 팀 이름·1차·2차 기록을 직접 입력/수정.
- **R** (기록 초기화): 그 팀의 1·2차 기록만 모두 지웁니다(팀은 유지). 잘못 눌러도 **↩ 되돌리기**로 복원.
- **D** (삭제): 팀을 목록에서 삭제.

## 기록 직접 입력 (수동)
- 순위표의 각 행 **E** 버튼으로 언제든 기록을 타이핑해 입력/수정할 수 있습니다.
- 입력 형식:
  | 입력 예시 | 해석 |
  |---|---|
  | `01:23.4` | 1분 23.4초 |
  | `1:05` | 1분 5초 |
  | `83.4` | 83.4초 (콜론 없으면 **초 단위**) |
  | (빈칸) | 기록 없음 |
- 기록은 비워둬도 됩니다(예: 1차만 입력). 나중에 행의 **E**(수정)로 채울 수 있습니다.

## 🏆 시상식 (레이스 종료 연출)
- 상단 **`🏆 레이스 종료 · 시상식`** 버튼을 누르면 1위 팀 발표 화면이 뜹니다.
- **팡파레 사운드 + 컨페티(색종이)** 가 터지고, 우승팀 이름·최고기록과 2·3위가 함께 표시됩니다.
- **↻ 다시 보기**로 연출을 재생, **닫기**(또는 Esc·배경 클릭)로 종료합니다.
- 발표 모드(프로젝터)에서도 그대로 작동합니다. 사운드는 인터넷 없이 재생됩니다.
  - (참고: 브라우저 정책상 첫 소리는 버튼 클릭 같은 사용자 동작이 있어야 납니다 — 시상식 버튼 클릭이 그 역할을 합니다.)

## 순위 규칙
- 각 팀의 **1차·2차 중 더 빠른 기록(BEST TIME)** 으로 **오름차순** 정렬됩니다.
- 기록이 하나도 없는 팀은 맨 아래로 갑니다.
- 1·2·3위는 🥇🥈🥉 메달과 색상 배지로 강조되며, 상단 **포디움(TOP 3) 카드**에 크게 표시됩니다.

## 행 편집 / 삭제
- 각 행 오른쪽 **E** = 팀명·기록 인라인 수정 (✓ 저장 / ✕ 취소, Enter·Esc 지원)
- **D** = 해당 팀 삭제 (확인 후)

- **Space** : 스톱워치 시작/정지

- **Enter** : 입력 폼/수정칸에서 확정

## 기술 메모
- 순수 HTML/CSS/JavaScript 단일 파일. 외부 라이브러리·CDN·서버 없음 → 100% 오프라인.
- 저장 위치: 브라우저 `localStorage` 키 `seame2026.teams`.
- 시간 정밀도: 내부적으로 밀리초(ms)까지 저장, 화면 스톱워치는 0.1초 단위 표시.
