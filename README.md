# 2026 SEA:ME HACKATHON — 스케일카 레이스 스톱워치 & 랭킹

스케일카 자율주행 대회의 팀별 주행 기록을 측정하고 실시간 순위를 매기는 도구입니다.
**인터넷·설치·로그인이 전혀 필요 없습니다.** `index.html` 파일을 더블클릭하면 끝.

---

## 빠른 시작
1. `index.html`을 더블클릭해서 브라우저(크롬/엣지 권장)로 엽니다.
2. 데이터는 브라우저에 자동 저장됩니다(localStorage). 새로고침·재실행해도 유지됩니다.

> ⚠️ **현장 운영 팁**: 대회 시작 전 노트북·브라우저를 정하고 끝까지 같은 환경에서
> 쓰세요. 데이터는 해당 브라우저에만 저장됩니다. 만일을 대비해 중간중간
> **💾 백업(JSON)** 을 눌러 파일로 저장해두면 다른 PC로도 옮길 수 있습니다.

---

## 사용 순서

### STEP 1 — 팀 먼저 등록
- 좌측 **STEP 1 · 팀 등록**에서 팀 이름을 입력하고 **＋ 등록**(또는 Enter).
- 기록은 비워두면 됩니다 — 레이스 때 타이머로 측정해 채웁니다.
- 등록한 팀들이 바로 우측 순위표에 나타납니다.

### STEP 2 — 레이스 측정 (타이머 자동 저장)
1. **현재 주행 팀**을 드롭다운에서 선택합니다. (배지에 `다음 ▶ 1차`처럼 다음 저장 칸 표시)
2. 차가 출발하면 **시작**(또는 Space), 결승선 통과 시 **정지**(또는 Space).
3. **정지하는 순간 그 팀의 다음 빈 칸(1차 → 2차)에 자동 저장**되고 타이머는 0으로 리셋됩니다.
   - 같은 팀이 한 번 더 달리면 → 정지 시 자동으로 **2차**에 들어갑니다.
   - 잘못 저장됐으면 화면 하단 알림의 **↩ 되돌리기**를 누르세요.
4. 자동 저장을 원치 않으면 **`정지 시 다음 기록 칸에 자동 저장`** 토글을 끄고,
   **수동 적용**의 `1차에 적용` / `2차에 적용` 버튼으로 직접 넣습니다.

> 두 기록이 모두 찬 팀은 정지해도 덮어쓰지 않습니다. 수정하려면 순위표의 **E** 또는 수동 적용 버튼을 쓰세요.

## 기록 직접 입력 (수동)
- **STEP 1**의 **`▾ 기록 직접 입력 (선택)`** 을 펼치면 1차·2차 기록을 타이핑해서 바로 등록할 수 있습니다.
- 순위표의 각 행 **E** 버튼으로 언제든 기록을 수정할 수 있습니다.
- 입력 형식:
  | 입력 예시 | 해석 |
  |---|---|
  | `01:23.4` | 1분 23.4초 |
  | `1:05` | 1분 5초 |
  | `83.4` | 83.4초 (콜론 없으면 **초 단위**) |
  | (빈칸) | 기록 없음 |
- 기록은 비워둬도 됩니다(예: 1차만 입력). 나중에 행의 **E**(수정)로 채울 수 있습니다.

---

## 순위 규칙
- 각 팀의 **1차·2차 중 더 빠른 기록(BEST TIME)** 으로 **오름차순** 정렬됩니다.
- 기록이 하나도 없는 팀은 맨 아래로 갑니다.
- 1·2·3위는 🥇🥈🥉 메달과 색상 배지로 강조되며, 상단 **포디움(TOP 3) 카드**에 크게 표시됩니다.

---

## 행 편집 / 삭제
- 각 행 오른쪽 **E** = 팀명·기록 인라인 수정 (✓ 저장 / ✕ 취소, Enter·Esc 지원)
- **D** = 해당 팀 삭제 (확인 후)

## 상단 도구 모음
| 버튼 | 기능 |
|---|---|
| 📺 **발표 모드** | 좌측 입력 패널을 숨기고 랭킹 표를 크게 표시 → **프로젝터/대형 스크린용**. 다시 누르면 운영 모드로 복귀 |
| ⬇ **결과 CSV** | 최종 순위표를 엑셀에서 열 수 있는 CSV로 저장 |

| 📂 **복원** | 백업 JSON 파일을 불러와 복원 (현재 데이터 덮어씀) |
| 🗑 **전체 초기화** | 모든 기록 삭제 (2번 확인) |

## 키보드 단축키
- **Space** : 스톱워치 시작/정지
- **R** : 스톱워치 리셋
- **Enter** : 입력 폼/수정칸에서 확정

## 기술 메모
- 순수 HTML/CSS/JavaScript 단일 파일. 외부 라이브러리·CDN·서버 없음 → 100% 오프라인.
- 저장 위치: 브라우저 `localStorage` 키 `seame2026.teams`.
- 시간 정밀도: 내부적으로 밀리초(ms)까지 저장, 화면 스톱워치는 0.1초 단위 표시.
